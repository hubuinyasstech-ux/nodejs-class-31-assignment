# Node.js Class 31 Assessment
A simple Node.js project from Class 31, focused on working with CSV data, file handling, buffers, and performance.

## What it does
Generates a CSV file containing 10,000 sales records.
Reads and processes the sales data.
Calculates the total revenue.
Summarizes revenue by country and writes the result to summary.csv.
Can be run with both Node.js and Bun.
Run the Project
Using Node.js:

node generate.js
node parse-buffer.js
node write-summary.js
Using Bun:

bun generate.js
bun parse-buffer.js
bun write-summary.js
The generated results are saved in summary.csv.
